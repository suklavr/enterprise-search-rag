# How do I run a probabilistic analysis in Portfolio Manager?
Open the portfolio, choose Run Analysis, pick Probabilistic, select or create analysis settings (frequency and severity distributions, number of simulation years, conservative/default/aggressive rates) and press Run. The analysis appears in the analyses list; large portfolios can take over an hour.
