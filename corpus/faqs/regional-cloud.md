# Does the model distinguish regional and global cloud outages?
Yes, since v6. For the regional cloud service provider scenarios 36 to 40 the model simulates single-region, multi-region and global outages, and multi-region outages share one Event Occurrence ID so the OEP treats them as one occurrence.
