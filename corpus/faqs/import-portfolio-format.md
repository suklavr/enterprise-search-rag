# What file format does the portfolio import accept?
CSV or XLSX using the import template. Required columns include company name, website or domain, country, industry, revenue, contract type, limit, deductible and the v6 fields Patch Management, Network Segmentation and Data Backup Frequency. Rows failing validation are listed in the import report.
