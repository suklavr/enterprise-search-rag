# My analysis has been running for hours. Is it stuck?
Portfolios above 100,000 policies at 50,000 simulation years can take several hours, longer with Calculate Account Level Metrics enabled. If the status has not changed for more than 6 hours, raise a support ticket with the analysis ID.
